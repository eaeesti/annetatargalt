# Site

The public site at https://annetatargalt.ee/, in Next.js 16 and Tailwind CSS 4.
Its pages and texts come from the Strapi backend in `../backend`. See the
repository's [README](../README.md) to set it up and [AGENTS.md](AGENTS.md) for
how the code is organised.

```bash
pnpm dev        # http://localhost:3000, with the backend running
pnpm check      # lint, type check and tests
pnpm build      # production build
```
